# Fire Fighting Robotic Car

This project is an Arduino-based firefighting robot designed to detect and extinguish small fires automatically.

## Components Used
- Arduino Uno
- Flame Sensor
- L298N Motor Driver
- DC Motors
- Water Pump
- Robot Chassis

## Working
The flame sensor detects fire and sends signals to the Arduino.  
The robot moves towards the fire and activates a water pump to extinguish it.
