# Autonomous Fire Fighting Robot

## Overview
The Autonomous Fire Fighting Robot is an embedded systems project developed using Arduino. The robot is designed to automatically detect fire using a flame sensor, navigate towards the fire source, and activate a water pump to extinguish it. This project demonstrates sensor interfacing, motor control, real-time decision making, and embedded programming concepts.

## Features
- Automatic flame detection
- Autonomous movement towards fire source
- Water pump activation for fire suppression
- Real-time sensor monitoring
- Embedded control using Arduino

## Hardware Components
- Arduino Uno
- Flame Sensor
- L298N Motor Driver
- DC Motors
- Water Pump Module
- Robot Chassis
- Battery Pack

## Software
- Arduino IDE
- Embedded C / Arduino Programming

## System Workflow
1. Flame sensor continuously monitors for fire.
2. Arduino processes sensor data.
3. Robot navigates towards the detected flame.
4. Water pump is activated upon reaching the fire source.
5. Fire is extinguished automatically.
